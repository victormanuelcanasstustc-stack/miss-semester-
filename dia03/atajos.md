# Día 3 — Mis 15 atajos de VS Code

| N.º | Atajo | Función |
|---|---|---|
| 1 | Ctrl + P | Abrir rápidamente un archivo. |
| 2 | Ctrl + Shift + P | Abrir la paleta de comandos. |
| 3 | Ctrl + S | Guardar el archivo. |
| 4 | Ctrl + ` | Abrir o cerrar la terminal integrada. |
| 5 | Ctrl + B | Mostrar u ocultar la barra lateral. |
| 6 | Ctrl + Tab | Cambiar entre archivos abiertos. |
| 7 | Ctrl + W | Cerrar el archivo actual. |
| 8 | Ctrl + F | Buscar texto en el archivo. |
| 9 | Ctrl + H | Buscar y reemplazar texto. |
| 10 | Alt + Flecha arriba/abajo | Mover una línea de código. |
| 11 | Shift + Alt + Flecha abajo | Duplicar una línea. |
| 12 | Ctrl + / | Comentar o descomentar una línea. |
| 13 | F12 | Ir a la definición de una función. |
| 14 | Shift + F12 | Buscar referencias de un elemento. |
| 15 | Shift + Alt + F | Formatear el documento. |

## Práctica

Se practicaron los atajos para abrir archivos, cambiar entre
documentos, navegar por el código, editar líneas, buscar texto,
guardar y formatear archivos sin utilizar el ratón.

## Atajos adicionales de depuración

- F9: activar o quitar un breakpoint.
- F10: avanzar sobre la siguiente línea.
- F11: entrar en una función.
- Shift + F5: detener la depuración.
