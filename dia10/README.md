# Actividad 10 – Beyond the Code

## Objetivo

Analizar las prácticas que rodean el desarrollo de software y aplicarlas al repositorio del curso mediante mejoras documentadas y commits de Git.

## Contenido de la actividad

- `resumen_clase.md`: resumen de los tres temas principales de la clase 8.
- `reflexion_y_plan.md`: reflexión sobre el tema menos familiar y plan personal de aprendizaje para los próximos tres meses.
- `pendientes_dias01_09.md`: revisión de tareas incompletas o que requieren verificación de las actividades anteriores.
- `evidencias/`: evidencias de las mejoras aplicadas al repositorio.

## Prácticas aplicadas

1. Mejorar la documentación de un proyecto para facilitar su comprensión, instalación y utilización.
2. Documentar decisiones técnicas explicando sus motivos y consecuencias.

## Evidencia en Git

Cada práctica cuenta con un commit independiente para identificar los cambios realizados y comprobar su aplicación.
